# Monitoring

Recommended production telemetry:
- OpenTelemetry traces and metrics
- OTLP exporter
- API latency/error-rate dashboards
- queue depth/failed-job dashboards
- PostgreSQL connection/latency metrics
- Redis memory/eviction metrics
- mobile crash/error reporting

Do not put private Scripture notes, prayer text, access tokens or full AI prompts into telemetry attributes.
